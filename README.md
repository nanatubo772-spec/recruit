# ななつぼ 井土ヶ谷店・求人ページ案

ページ本体は `dist/` にあります。画像、CSS、リンクは GitHub Pages のリポジトリ名付きURLでも動くよう相対パスにしています。

## 文章や募集条件の差し替え

`dist/content-config.js` を編集すると、ページの次の箇所をHTMLに触れず変更できます。

- 01：見出し、説明、2つの魅力カード
- 02：見出し、説明、3枚の画像・代替テキスト・キャプション
- 03：見出し、説明、募集条件、募集状況、応募電話、店舗電話

時給などの募集条件は `conditions` の各行を編集します。電話番号は `contact` 内を変更してください。文字列を囲む引用符と、各項目末尾のカンマは消さないでください。

店頭の募集掲示をもとに、18:00〜23:00、1日3時間〜・週2日でも可、希望シフト制、まかない付きなどを掲載しています。掲示の時給1,100円〜は現在の神奈川県最低賃金を下回るため、ページでは「確認中」としています。2026年9月時点の最低賃金は1,225円、2026年10月1日からは1,279円です。必ず最新の時給を店長へ確認してから公開してください。応募受付は掲示記載の 045-334-7811、店舗問い合わせは 045-308-7411 です。募集の継続状況と電話番号も最終確認してください。

店長写真は掲載しない構成です。店の雰囲気は文章と店内写真で伝えます。お好み焼きの写真は料理イメージであり、実際のまかないの写真ではありません。

## GitHub Pages の更新

`main` ブランチへ変更をプッシュすると、GitHub Actions が `dist/` を自動公開します。必要な場合は **Actions → Publish recruitment page → Run workflow** から手動でも再公開できます。

公開URLをスマートフォンで確認してから、そのURLを使ってチラシ用QRコードを作ります。

公開前に、写真の使用可否と応募先の表記も店長に確認してください。以前の非公開プレビューURLはチラシ用には使いません。
