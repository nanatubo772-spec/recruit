# ななつぼ 井土ヶ谷店・求人ページ案

ページ本体は `dist/` にあります。画像、CSS、リンクは GitHub Pages のリポジトリ名付きURLでも動くよう相対パスにしています。

現在は相談用の案です。仕事内容・給与・勤務時間・雇用形態・応募方法は未確認です。公開されている店舗電話番号 045-308-7411 を仮の問い合わせ先として掲載していますが、採用受付に使えるか店長へ確認してください。募集条件と応募窓口を確定させてから公開してください。

「明るくて頼りになる店長」「無料の賄い」は相談中の仮文言です。公開前に店長へ確認し、店長と賄いのダミー写真枠を実際の写真へ差し替えます。お好み焼きの写真は料理イメージであり、賄いの写真ではありません。

## GitHub Pages で公開するとき

1. このリポジトリを GitHub に置きます。
2. リポジトリの **Settings → Pages → Build and deployment** で **GitHub Actions** を選びます。
3. 募集内容を確定させてから、**Actions → Publish recruitment page → Run workflow** を実行します。
4. 公開されたURLをスマートフォンで確認し、そのURLからチラシ用QRコードを作ります。QRコードは公開URLが決まるまで印刷しません。

公開前に、写真の使用可否と応募先の表記も店長に確認してください。以前の非公開プレビューURLはチラシ用には使いません。
